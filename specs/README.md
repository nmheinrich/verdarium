# Specs

One file per feature, named `NNN-short-slug.md`. Copy `_template.md` to start a new one.

**Status values:** `draft` → `agreed` → `in progress` → `shipped` (or `on hold` / `dropped`).

A spec is required for anything that changes user-facing behaviour, the data model, or Supabase schema. Small fixes don't need one.
